## Legenda skrótów

| Skrót     | Znaczenie                                                                                                            |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| DTR       | Dokumentacja Techniczno-Ruchowa                                                                                      |
| DTE       | Dokumentacja Techniczna Eksploatacyjna (opakowanie/dokumenty zgłoszeniowe Michelin)                                  |
| DTM       | Klasyfikacja dokumentów Michelin (np. 2-03-01 montaż, 2-04-00 pakowanie, 3-03-00 instalacja, 5-01-00 bezpieczeństwo) |
| DOC       | Numer dokumentu w systemie Michelin (np. DOC-000394563)                                                              |
| ZHU1-     | Nasza numeracja rysunków (prefiks rysunków złożeniowych i detalicznych)                                              |
| DES       | Numer rysunku/montażowego w systemie Michelin (np. DES-000814472) – występuje w przykładach                          |
| PF        | Numer formularza/wzoru w systemie Michelin (np. 01468-04007-PF)                                                      |
| ŚOI       | Środki Ochrony Indywidualnej (kask, obuwie, okulary, rękawice, kamizelka itd.)                                       |
| UDT       | Urząd Dozoru Technicznego (przeglądy i dopuszczenia urządzeń, np. wózków, suwnic)                                    |
| LOTO      | Lockout-Tagout – procedura blokowania i oznaczania źródeł energii na czas prac                                       |
| PED       | Dyrektywa ciśnieniowa 2014/68/UE (sprzęt pod ciśnieniem)                                                             |
| CE / WE   | Oznakowanie zgodności / dyrektywa maszynowa 2006/42/WE                                                               |
| RB        | Protokół/raport z badań/odbioru UDT (np. 2602517_01_48_RB_2026)                                                      |
| rep.      | Repere – pozycja zespołu na rysunku złożeniowym                                                                      |
| PAP / BNS | Nazwy maszyn objętych dokumentacją                                                                                   |
