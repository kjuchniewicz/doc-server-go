# Dokumentacja DTR – przykładowa struktura

To jest **przykładowe** drzewo dokumentów. Skopiuj folder `dokumenty-example/` jako `dokumenty/` i uzupełnij go rzeczywistą zawartością dla swojego projektu.

## Wymagana struktura

```text
dokumenty/
├── PAP/
│   └── DTR/
│       └── 01_Instrukcja montazu - Konstrukcja mechaniczna.md
├── BNS/
│   └── DTR/
│       └── 01_Instrukcja montazu - Konstrukcja mechaniczna.md
└── Wspolne/
    └── 10_Ryzyko resztkowe - suwnica - BHP.md
```

Nazwa działu odpowiedzialnego powinna znajdować się na końcu nazwy pliku, po ostatnim
separatoze ` - `, przed rozszerzeniem `.md`.
